# Casa Buona Vita — 3D navegável

Modelo 3D da casa no formato do [Sweet Home 3D](https://www.sweethome3d.com/), exibido com o Sweet Home 3D JS Viewer 7.5.2.

- Página: https://aquinogr.github.io/buonavita/
- Arquivo editável: `buonavita-existente.sh3d` (abre no Sweet Home 3D 7.x)

A geometria (paredes, vãos, portas, janelas, níveis e alturas) foi tirada das plantas e dos cortes do projeto arquitetônico. Móveis, cores e texturas são ilustrativos.
Créditos dos modelos 3D em `creditos.html` (Free Art License 1.3). Visualizador sob GPL.
